什么是 MCP？

Model Context Protocol（模型上下文协议）是由 Anthropic 提出的开放标准协议，让 AI 模型能够安全、标准化地与外部工具、数据源和_services交互。

标准化接口

统一的协议规范，任何 MCP 兼容客户端都可以连接任何 MCP 服务器

安全隔离

本地运行，数据不外流；细粒度权限控制，保障隐私安全

生态丰富

涵盖开发工具、数据库、云服务、通讯协作等各领域生态

🚀 快速开始

只需 3 步，即可将 MCP 服务器接入你的 AI 工具

1

安装 Claude Desktop 或兼容客户端

MCP 协议被 Claude Desktop、Cursor、Windsurf 等主流 AI 工具原生支持

# macOS (Homebrew)
brew install --cask claude
2

配置 MCP 服务器

在 Claude Desktop 设置中添加服务器配置（以 GitHub 为例）

# ~/.claude.json (macOS) 或 %APPDATA%\Claude\claude_desktop_config.json (Windows)
{ "mcpServers": { "github": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"] } } }
3

开始使用！

重启客户端后，直接用自然语言让 AI 调用 MCP 工具完成复杂任务

💬 示例对话

"帮我查看最近的 5 个 Issue，并把还没分配的分配给我"
